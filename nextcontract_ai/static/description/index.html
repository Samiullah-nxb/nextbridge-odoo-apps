NextContract AI

AI-assisted field extraction and clause analysis

  • Extract contract fields as suggestions that a reviewer accepts or rejects
  • Compare inbound clauses with your clause library and flag deviations and risk
  • Works with Google Gemini, OpenAI, Anthropic Claude and OpenAI-compatible servers (Ollama, vLLM, LM Studio, OpenRouter)
  • Several providers side by side, with a default and a fallback model each; choose the provider and model per run
  • A review queue with confidence scores and the source text of every suggestion

External service

AI processing uses the provider you configure under Configuration, AI Providers, with your own API key, billed by that provider. Contract text and files are sent to a third-party provider only after an administrator has configured it and given cloud-processing consent in Settings. Consent can be revoked there. A server you host on your own network needs no consent.

This module is part of NextContract, contract lifecycle management for Odoo 19 Enterprise. Install the NextContract app to get the complete suite.
