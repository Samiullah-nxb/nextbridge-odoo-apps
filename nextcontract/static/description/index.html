Your contracts stay yours

Everything lives in your own Odoo database. AI is off until an administrator connects a provider and gives cloud-processing consent, which can be revoked at any time. A model you host on your own network keeps contracts in-house and needs no consent. The Word editor runs in the browser and saves to your Odoo server.

What you need

•  Odoo 19.0 Enterprise, self-hosted (not Odoo Online)
•  Documents, Sign and Employees apps (Purchase is optional)
•  LibreOffice on the server for Word-accurate PDFs
•  Python packages from requirements.txt
•  Chrome or Edge
