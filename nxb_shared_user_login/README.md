# Shared User Login with Employee PIN

Odoo 18 app by **Nextbridge** (https://www.nextbridge.pk) - License OPL-1 - Support: samiullah.3277@nxb.com.pk

Several employees use one shared Odoo user (shop floor, warehouse, front desk). After the normal login, each one
picks their name and types their PIN; chatter messages, notes, field tracking, Discuss messages and e-mails then
carry the employee's name. Switch employee, idle lock, PIN lockout, sign-in history, external API protection.

Technical name: `nxb_shared_user_login`. Depends on `mail` and `hr`. See `doc/USER_GUIDE.md`.
