Shared User Login with Employee PIN

On a shared screen – shop floor, warehouse, front desk, workshop – several employees use the same Odoo user. Each one signs in with a personal PIN, and Odoo shows who wrote every message, note and e-mail.

Odoo 18 Works on every app, including custom ones PIN lockout & idle lock Sign-in history

How it works

  1. The shared user logs in as usual (login and password).
  2. A "Who is working?" screen appears: the employee taps their name and types their PIN (keyboard or on-screen keypad).
  3. Odoo opens with the employee's name and photo in the top bar. Everything they post is signed with their name.
  4. Switch employee from the user menu hands the screen to a colleague in two seconds.

Features

  • Employee as author of chatter messages, logged notes, field-change tracking, Discuss messages and outgoing e-mails – on every model, including apps installed later and custom modules.
  • Customers see the employee's name (and work e-mail when set) on e-mails; replies still reach the shared account.
  • Nothing is reachable before the PIN: pages, data calls and downloads all wait until an employee has signed in.
  • Switch employee and Change my PIN in the user menu.
  • Idle lock: ask for the PIN again after a chosen number of idle minutes.
  • PIN lockout: after a number of wrong PINs the employee is locked for a while (both configurable); HR can unlock.
  • Sign-in history: every sign-in, switch, idle lock, wrong PIN and PIN change with date and IP address.
  • Safe by default: administrator and portal accounts cannot be shared, and the external API (XML-RPC/JSON-RPC) is refused for shared accounts unless you allow it.

Set up in three steps

  1. Settings → General Settings → Users: switch on Shared user accounts (and choose the idle lock and PIN lockout).
  2. Give each employee a PIN (employee form → Settings tab → PIN Code – the same PIN Odoo uses for attendance).
  3. Open the user to share → Shared account tab → tick it and add the employees.

Questions

What does it depend on?
Discuss (mail) and Employees (hr) only.

Do record "Created by" fields change?
No: Odoo still records the shared user there. The employee's name is on the messages, notes, tracking and e-mails of each record, and in the sign-in history.

Does a shared account replace Odoo user licences?
This app is about knowing who did what on a shared screen. Odoo Enterprise subscriptions are priced per person using the system: check your subscription terms before sharing an account between several people.

Is it tested?
The app ships with an automated test suite (PIN screen, lockout, idle lock, switching, attribution on chatter, Discuss and e-mail, external API protection).
