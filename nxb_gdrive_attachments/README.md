# Google Drive Attachment Storage

Odoo 18 app by **Nextbridge** (https://www.nextbridge.pk) - License OPL-1 - Support: samiullah.3277@nxb.com.pk

Sends the files attached to Odoo documents to Google Drive automatically (one folder, one folder per document
type, or one folder per record) and keeps Drive in step when files are replaced, renamed, re-attached or deleted.
Copy mode keeps the files in Odoo too; Move mode frees Odoo storage and Odoo reads the files back from Drive.
Google account (OAuth) or Workspace service account with Shared Drives. No extra Python package.

Technical name: `nxb_gdrive_attachments`. See `doc/USER_GUIDE.md`.
