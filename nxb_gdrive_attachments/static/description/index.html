Google Drive Attachment Storage

Every file attached to an Odoo document is sent to Google Drive automatically, in tidy folders. Keep a copy in Odoo, or move the files out of Odoo to free its storage – people keep working exactly as before.

Odoo 18 Folders per document type or per record Update, rename & delete sync Shared Drives & service accounts

What it does

  • Automatic upload of every new attachment: chatter files, e-mail attachments, generated PDFs, imported documents.
  • Three folder structures: one folder, one folder per document type (Sales Order, Invoice...), or one folder per record (Sales Order / S00016).
  • Stays in step: replacing a file updates it on Drive, renaming renames it, attaching it to another record moves it, deleting it moves it to the Drive trash (or deletes it, or keeps it – your choice).
  • Drive link on every attachment, and an option to make files viewable by anyone with the link.
  • Copy or Move: keep files in Odoo with a Drive copy, or move them out of Odoo. Moved files still open, download, preview and go out by e-mail as usual: Odoo reads them from Drive (with a local cache and an integrity check).
  • Existing attachments are sent in one click, and every file can be brought back into Odoo at any time.
  • Choose what goes: all documents or selected document types, minimum size, images in fields and public files on or off.
  • Background sync with automatic retries, an activity log and a list of every file and folder.

Simple, safe setup

  1. In Google Cloud Console, enable the Google Drive API and create an OAuth client of type Web application. Add the redirect URI shown in Odoo.
  2. In Settings → Google Drive, switch the storage on, enter the Client ID and secret, Save, then click Connect Google account and allow access.
  3. Choose Copy or Move, the folder structure and which files go. Click Test connection. Done: new attachments go to Drive within seconds.

Google Workspace? Use a service account with a Shared Drive instead of a personal account. By default the app only asks Google for access to the files it creates.

Built to be trusted with your files

  • Uploads and deletions run in the background, after the user's change is saved: a cancelled operation never leaves Drive out of step and nobody waits for Google.
  • A file is only released from Odoo once Drive holds exactly the same content (checksums), and files read back from Drive are checked again.
  • The app refuses to be uninstalled while files exist only on Drive, so no document can become unreadable.
  • Multi-company: each company has its own Google connection, folders and rules.

Questions

Which files are sent?
Files attached to records (chatter, e-mails, reports saved as attachments, imports). Odoo's technical files (views, assets) never are; product images and other images stored in fields only when you switch that on.

Do users need a Google account?
No. Users keep opening files in Odoo. The Drive link opens the file on Drive for people who have access to it, or for everyone when "Anyone with the link" is on.

What if Google is unreachable?
Uploads are retried automatically. In Move mode, recently read files come from the local cache.

Dependencies?
None besides Odoo itself: no Google library to install.
